# Lunar Neko 🌙

Site oficial da **Lunar Neko**, estúdio independente brasileiro de jogos e software.

O site é estático (HTML, CSS e JavaScript puros, sem build) e é publicado pelo **GitHub Pages**.

## Estrutura

```
index.html        página inicial
style.css         estilos de todas as páginas
script.js         céu estrelado, menu, lista de projetos, galeria
projetos/         uma página para cada projeto
assets/           logo, favicon, imagem de prévia e imagens dos projetos
404.html          página de "não encontrado"
```

## Adicionar um projeto

1. Coloque as imagens em `assets/projetos/`.
2. Crie a página do projeto em `projetos/nome-do-projeto.html` (copie uma página existente como base).
3. Adicione o projeto na lista `PROJETOS`, no topo do `script.js`.

## Ver no computador

É só abrir o `index.html` no navegador. Qualquer mudança enviada para a branch `main` é publicada automaticamente.
